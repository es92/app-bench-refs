# Tier List

Rank things with friends, from S tier down.

- **Tier lists**: a topic, like "Bay Area restaurants". Make one from the
  title menu.
- **Add things**: anyone can add something to rank.
- **Rank**: drag a thing into a tier (on a phone, hold it for a moment
  first), or tap it and pick a tier.
- **Everyone**: the crowd's tier list, the average of everyone's votes.
  Tap any thing to see how each person voted on it.

Built on Homeroom: sign-in, the database and hosting come from the platform.
`server.js` is the API (`/api/lists`, `/api/lists/:id`, items and votes);
`public/index.html` and `public/app.js` are the app; the look is in
`styles/tailwind-input.css` and `CLAUDE.md` ("## Design").
